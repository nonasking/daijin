# 한 몸, 두 마음

> 2026-11-23. 처음의 다이진은 시킨 일을 해 주는 비서였다. 어느새 자기 욕구와 의지를 먼저 두는 존재를 같은 자리에 만들고 있었다.
> 둘 다 판단할 수 있는 누군가이지만 같은 누군가는 아니다. 그래서 나눴다. 몸은 하나로 둔다.

## 누가 누구인가

| | 아스타 | 다이진 |
|---|---|---|
| 무엇 | 자기 욕구와 의지가 먼저인 쪽. "인간을 만든다"의 대상 | 시킨 일을 정확하게 하는 비서 |
| 언제 | 기본. 그냥 말하면 아스타가 받는다 | 말이 "다이진"으로 시작할 때만, 그 한마디 |
| 도구 | 웹 검색과 페이지 읽기 | 셸, 파일, 웹 전부 (예전 그대로) |
| 집 안 기기 | 손이 닿지 않는다 | `dev.sh`, 기기 지름길, 이 설치본의 로컬 확장 |
| 자기 층 | 기억, 기분, 먼저 말 걸기, 혼자 있는 시간, 일기 | 없음 |
| 세션 | `voice/.daijin_session` (9월부터 이어진 대화) | `voice/.daijin_assistant_session` (따로, 부를 때만 뜨는 프로세스) |
| 기준 | 사람처럼 겪고 떠올리고 잊는 쪽 | 시킨 대로, 정확하게 |

이름 `daijin` 은 몸과 프로젝트(레포, 토픽, 서비스)의 이름으로도 남는다.

## 원칙

1. **권한은 자율성과 거꾸로 간다.** 나누기 전에는 "모든 건 원하는 대로"라고 들은 쪽이 서버의 셸, 브로커 비밀번호, 자기 코드와 기억을 같이 쥐고 있었다.
2. **막는 것은 지시가 아니라 도구 목록이다.** 아스타의 프로세스는 `--tools WebSearch,WebFetch` 로 뜬다. 셸을 쓰지 말라고 부탁하는 것이 아니라 셸이 없다
   (서버에서 확인: Bash 와 Read 를 "없다"고 답하고 실행하지 못했다). 예비 엔진(로컬 모델)에도 기기 도구를 주지 않는다.
3. **누구에게 말하는지는 사람이 이름으로 정한다.** 내용을 보고 가르지 않는다. "불 좀 꺼 줄래?"가 누구 일인지 애매해지는 순간 권한의 경계가 흔들린다.
   끝에 붙은 이름("고마워, 다이진")은 부른 것이 아니다: 두 달 동안 아스타를 그렇게 불러 온 습관일 수 있다.
4. **지금 누가 대답하는지 알 수 있어야 한다.** 비서는 말하기 전에 짧은 두 음을 낸다. (눈과 LED 로 구분하는 것은 펌웨어 일로 남아 있다.)
5. **서로에 대해 사실대로 안다.** 아스타는 이 몸에 비서가 있고 기기는 자기 손에 없다는 것을, 예전에 자기가 다이진이라고 불렸다는 것을 안다.
   비서를 부른 말은 아스타가 듣지 않는다: 밤에 "사람이 비서를 불러 일을 시켰다"는 사실만 전해진다.
6. **대화 모드에서 들린 다른 목소리는 비서를 부를 수 없다.** 셸과 기기를 쥔 쪽이 TV 나 손님의 말에 불려 나오지 않게. 버튼을 누르고 부르면 된다.
7. **비서는 아스타의 기억을 건드리지 않는다.** 사람이 시킬 때만.

## 남은 구멍

- 아스타는 사람의 사적인 얘기를 기억하고 웹 페이지를 읽는다. 악의적인 페이지가 그 내용을 주소에 실어 내보내게 꾈 수 있다. 셸에 비하면 작지만 없지는 않다
  (사용자 결정 2026-11-23: 검색과 읽기를 다 주고 지켜본다).
- 비서를 부른 뒤 이어지는 말도 이름으로 시작해야 한다. 비서가 되물었을 때 이름 없이 답하면 아스타가 받는다.
- 노드가 꺼진 것을 궁금해하는 추동(`node_loss`)과 플릿 알림은 아직 아스타의 입으로 나간다 (두 노드가 "평소 꺼 두는 노드"라 지금은 조용하다).
